This branch includes _files_ for the **Development and Psychometric Evaluation of the Emotional Dependency in AI Chatbots Scale (EDCS)**

Includes:
1) **Content Validity Analysis** with the **mcontent validity metrics computation** script (_content_validity_evaluation_func.R_) that is used by the final scrip (_content validity final.R_).
2) The **Demographcis** script (_Demographics_EDCS.R_)of the final dataset of all 47, pre-factor analysis, items.
3) The **Exploratory Factor Analysis script** (_EFA_Analysis.R_).

_All code was created with the R programming language, using the R studio interface_
